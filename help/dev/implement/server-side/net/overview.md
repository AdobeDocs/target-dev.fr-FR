# Présentation de .NET SDK

Ce guide de référence explique comment [!DNL Adobe Target] clients peuvent installer, initialiser et utiliser .NET SDK.

## Conditions requises

* Au minimum [.NET Standard 2.0](https://github.com/dotnet/standard/blob/v2.1.0/docs/versions/netstandard2.0.md)
* Recommandé [.NET 5](https://github.com/dotnet/core/blob/main/release-notes/5.0/README.md)

## Prise en main

Pour découvrir comment commencer à utiliser .NET SDK, accédez au [[!DNL Target] Guide de prise en main de SDK](../sdk-guides/getting-started/getting-started.md).
