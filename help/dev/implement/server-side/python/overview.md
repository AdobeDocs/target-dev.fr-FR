# Présentation de Python SDK

Ce guide de référence montre comment [!DNL Adobe Target] clients peuvent installer, initialiser et utiliser le SDK Python.

## Conditions requises

Toutes les versions de Python actuellement conservées sont prises en charge, voir [Versions de Python](https://www.python.org/downloads/).

## Prise en main

Pour découvrir comment commencer à utiliser le SDK Python, accédez au Guide de prise en main de [[!DNL Target] SDK](../sdk-guides/getting-started/getting-started.md).
